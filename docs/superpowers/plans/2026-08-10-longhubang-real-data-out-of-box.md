# 龙虎榜真实数据开箱即用实施计划

日期：2026-08-10
状态：已完成
需求来源：[FlowAI Finance Skills 产品需求](../../requirements.md#龙虎榜真实数据自动获取)

## 1. 目标

使 `longhubang-analysis` 成为自包含、可安装、可自动取数的 Skill。用户只提供交易日期，Agent 即可获取真实龙虎榜汇总数据并在数据边界内完成分析。

## 2. 当前证据

- 仓库根目录存在 `scripts/fetch_longhubang.py`，使用东方财富 `RPT_DAILYBILLBOARD_DETAILSNEW`。
- Skill 安装器只打包 `skills/longhubang-analysis/`，导致已安装 Skill 缺失抓取脚本。
- `SKILL.md` 声称脚本“安装即可用”，但没有定义 Agent 在缺少用户数据时必须自动执行的行为。
- 当前校验器只检查 Markdown 链接，没有检查命令中引用的脚本。

## 3. 产品规则与非目标

- 数据必须来自用户提供内容或脚本可核验返回。
- 获取失败时不得继续生成事实性龙虎榜结论。
- 汇总数据不足以支持完整席位画像时必须降级为“信息不足”。
- 不接入账户、不自动交易、不输出个性化买卖指令。

## 4. 数据流

1. 用户提交交易日期。
2. Agent 定位当前 Skill 根目录。
3. Agent 执行 `python3 scripts/fetch_longhubang.py <date> --json`。
4. 脚本校验日期并请求东方财富公开接口。
5. 脚本按股票去重并输出带来源、日期和抓取时间的结构化结果。
6. Agent 按六步框架分析；缺失席位明细的部分明确降级。

## 5. 实施任务

### 任务 A：自包含打包

- 将抓取脚本移入 `skills/longhubang-analysis/scripts/`。
- 保持零第三方依赖。
- 验证单独复制 Skill 目录后脚本仍可运行。

### 任务 B：自动执行规则

- 更新 `SKILL.md`：区分用户已提供数据和仅提供日期两种入口。
- 定义成功、网络错误、接口错误、非交易日和信息不足行为。
- 更新 README 的安装与运行示例。

### 任务 C：防回归校验

- 扩展 `scripts/validate_skills.py`，检查 Skill 文档中引用的 `scripts/...` 文件。
- 增加抓取脚本单元测试，使用本地模拟数据，不依赖网络。
- 在 CI 中运行单元测试。

### 任务 D：验收

- 运行 Skill 结构校验。
- 运行单元测试。
- 在临时目录复制单个 Skill，运行 `--help` 和无效日期测试。
- 在允许联网时运行历史交易日真实数据冒烟测试。

## 6. 接口与兼容性

- CLI 保持 `fetch_longhubang.py YYYY-MM-DD [--json]`。
- JSON 顶层保留 `date`、`count`、`stocks`，新增字段必须向后兼容。
- 原仓库根目录调用方式将改为 Skill 内路径；README 同步更新。

## 7. 错误与重试

- 日期格式错误：退出码非零，并输出明确格式要求。
- 无数据：退出码非零，并提示可能是非交易日或数据尚未发布。
- 网络/API 错误：退出码非零；Agent 报告错误，不分析空数据。
- 本阶段不做无限重试，避免 Agent 长时间阻塞。

## 8. 发布、回滚与完成定义

- 发布前从干净目录执行校验和测试。
- 如第三方接口变更，可回滚脚本提交；Skill 仍允许用户手动提供数据。
- 完成定义：脚本随 Skill 安装、自动取数规则明确、验证和测试通过、真实接口冒烟测试有明确结果。

## 9. 执行结果

- 抓取脚本已移入 Skill 自身的 `scripts/` 目录。
- Skill 自动取数、失败处理和信息不足降级规则已生效。
- 结构校验、3 项单元测试和独立目录运行测试均通过。
- 真实汇总接口冒烟测试成功：`2026-08-07` 返回 68 条记录、66 只股票。
