# FlowAI Finance Skills 产品需求

更新日期：2026-08-10

## 股性分析开箱即用

### 产品决策

`stock-character-analysis` 必须作为自包含 Skill 发布。用户只提供六位A股代码时，Agent 从 Skill 目录运行随包脚本，自动获取日线并输出五维股性画像；用户也可以提供本地 CSV，整个流程不要求手工计算指标。

### 用户可见行为

- 用户可以直接要求“分析 600519 最近的股性”。
- Agent 自动获取截至最近交易日的前120根前复权日线，也支持指定截止日期。
- 输出必须包含数据来源、观察截止日、样本数、五维指标、阶段标签、证据与限制条件。
- 网络失败、字段缺失或样本少于61根时停止分析并报告真实错误。

### 数据所有权与边界

- 在线模式只读取东方财富公开行情，不读取交易账户、持仓或个人身份信息。
- 本地 CSV 只在用户环境内读取，不由脚本上传到第三方。
- 标签描述历史观察窗口，不构成股票质量评价、投资建议或未来预测。

### 成功标准

- 单独安装后包含 `SKILL.md`、分析框架和可执行脚本。
- 脚本只依赖 Python 标准库，支持在线取数、本地 CSV 和 JSON 输出。
- 自动化测试覆盖核心标签计算、短样本拒绝和高波动识别。
- README 提供安装、自然语言调用和命令行示例。

### 非目标

- 不提供买卖点、目标价、止损价、仓位建议、自动交易或收益承诺。
- 不根据价格行为推断主力、庄家或具体游资意图。

## 龙虎榜真实数据自动获取

### 产品决策

`longhubang-analysis` 必须作为自包含 Skill 发布：用户只提供交易日期时，Agent 从 Skill 目录运行随包安装的数据脚本，获取可核验的东方财富龙虎榜汇总及买卖前五席位后再执行六步解读。

### 用户可见行为

- 用户可以直接要求“分析 YYYY-MM-DD 的龙虎榜”，无需先复制数据。
- Agent 优先运行 `scripts/fetch_longhubang.py YYYY-MM-DD --json`。
- 成功时，输出必须标明数据来源、交易日期、抓取时间、统计口径与数据缺口。
- 网络失败、接口异常或日期无数据时，停止事实分析并报告原因，不补造数据。
- 明细接口部分失败或使用汇总模式时，受影响的席位画像和行为判断必须标记“信息不足”。

### 数据所有权与边界

- 数据源是东方财富公开数据中心接口，仓库不保存账号、Cookie 或金融账户信息。
- 数据脚本只读取公开行情数据，不执行交易，也不向第三方上传用户文件。
- 外部接口没有可用性承诺；Skill 应将失败视为可恢复的数据源错误。

### 成功标准

- 单独安装 `longhubang-analysis` 后，Skill 目录包含抓取脚本。
- 抓取脚本只依赖 Python 标准库，并支持 Markdown 与 JSON 输出。
- 仓库验证能发现 Skill 文档引用但未打包的本地脚本。
- 自动化测试覆盖日期校验、数据去重和输出口径。

### 非目标

- 本阶段不提供自动交易、荐股、收益预测或仓位建议。
- 本阶段不建设未经核验的游资个人身份映射库。
- 本阶段不保证第三方公开接口永久稳定。
