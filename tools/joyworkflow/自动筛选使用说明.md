# 自动筛选使用说明

当前版本见 [README](README.md) 和 [桌面应用使用说明](docs/桌面应用使用说明.md)。

普通 Mac 用户下载应用包，解压后双击，不需要安装 Python。源码运行用 Python 3.9+ 执行 `python3 app.py --data-dir ./data`，打开终端提示的本机地址。

## 页面顺序

1. 本地数据：按行情快照、历史行情、行业分类、五层资料等分类查看 SQLite 已保存的日期、来源与缺口。空目录首次不需要预先导入。
2. 我的策略：查看已保存版本，进入五层指标库选择指标、修改阈值，保存新版本。模板选择在策略筛选页。
3. 策略筛选：选择模板或载入保存版本后运行；自动校验本地缓存，再获取缺失、过期资料。可选择重新联网校验。
4. 历史筛选：本轮报告和历史列表在同一页，入选与不符、未核验、数据缺失分别保留。相同策略已有记录时提示回看或重新运行。

## 范围和异常

- 以来源收盘资料为准，显示实际行情日期。五层策略另核验交易日历和交易所证券名录；其他基础模板不要套用五层策略的完整性结论。
- 当前沪深A股研究，不含北交所；ST、退市等按列明条件排除。行业使用申万当前成分，不等于历史时点题材。
- 默认历史核验上限40只，最多120只；实际以上限参数为准。未检查的股票不视为不符合；当前不是全市场自动历史回测工具。
- 行情或行业源可能断线、限流或缺数据。有限自动重试后显示原因，可点“重试缺失数据”。旧记录不改写，日期更换时要求新建筛选，避免混用两天数据。
- 日K、复权因子、成交额和日期必须校验；不是用成交量估算成交额。公开源依次尝试的原因随证据保存。
- 公开请求默认直连。需继承系统代理时可在源码启动环境设置 `JOYWORKFLOW_MARKET_PROXY=environment`；TLS校验始终保留。
- 五层未选指标不参与判定；固定数据校验不可关闭；个人交易计划和纪律未提供时不作评价。公告目录核验不等同于全文审查。

## 保存和退出

默认桌面数据保存在用户应用支持目录；通过原生菜单可打开或切换文件夹。更新应用不覆盖外置数据。备份时退出后复制整个文件夹。关闭应用停止取数，不会后台持续更新。

虚构示例入口仅用于演示，明确标注；五层真实策略不接受示例替代。筛选与报告由规则代码计算，未调用 AI 模型，不自动交易，也不证明收益。
