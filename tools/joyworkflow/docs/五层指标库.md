# 五层量化指标库

2026-10-31。24项已实现的五层筛选条件，另有20期涨跌幅补充指标；10项固定数据校验单独展示。自定义规则版本：`youzi-five-layer-v1.1.0`。

入口：我的策略 → 参数与版本配置 → 添加指标。按层勾选，应用后调整比较方式和阈值，再保存新版本。未勾选的模板条件不再参与计算；未设置条件的层会明确标注，仍执行固定数据校验。

若从旧三个模板添加五层条件，页面会明确切换为五层自定义引擎，不隐藏叠加旧模板的固定门槛。原模板和已保存版本继续兼容。

## 市场环境

| ID | 指标 | 默认比较与阈值 | 计算口径 |
|---|---|---|---|
| M1 | 市场上涨占比 | >= 40% | 上涨证券数 ÷ 合资格同日有效证券数 × 100 |
| M2 | 市场跌停占比 | <= 1% | 按同日实际跌停价计算的跌停数 ÷ 有效证券数 × 100 |
| M3 | 炸板率 | <= 45% | 炸板未封数 ÷ (收盘涨停数 + 炸板未封数) × 100；无触板样本不适用 |
| M4 | 昨日涨停今日反馈 | >= -1% | 昨日涨停集合在今日的涨幅中位数；无合资格样本不适用 |

## 行业共振

|---|---|---|---|

| S4 | 行业5日超额收益 | >= 1百分点 | 申万行业指数5日涨跌幅 − 沪深300同区间涨跌幅 |
| S5 | 行业近5日上涨天数 | >= 3天 | 申万行业指数最近5个交易日中收盘高于前收的天数 |

## 价格结构

| ID | 指标 | 默认比较与阈值 | 计算口径 |
|---|---|---|---|
| P1 | 收盘价 / 前20日最高价 | > 1倍 | 同复权收盘价 ÷ 此前20交易日最高价，窗口不含当日 |
| P2 | 前五日成交额倍数 | >= 1.5倍 | 当日成交额 ÷ 此前5交易日成交额均值，不含当日 |

## 固定数据校验

以下项目不允许关闭或降低门槛；它们检查资料能否支撑计算，不属于用户可删减的选股偏好。

- 市场环境：交易日历与最近交易日，完整覆盖日历，行情日须为最近交易日。
- 市场环境：交易所证券名录，名录与上市日期可用。
- 市场环境：证券名录匹配率，至少98%。
- 市场环境：合资格行情覆盖率，至少98%；缺口另列。
- 市场环境：实际限价行情覆盖率，至少98%。
- 市场环境：沪深300历史，真实有效历史基准可用。
- 行业共振：行业行情覆盖率，至少95%。
- 行业共振：行业有效成员数，至少10只。
- 行业共振：行业与基准日期对齐，最近6个观测与交易日历一致。
- 价格结构：个股OHLC连续与一致，最近61交易日连续、正数有效且价格口径一致。

同日有效、非ST/退市标记、上市至少120交易日仍是该引擎的合资格范围。上市天数采用已覆盖日历计数下界，不能声称是所有老股票的精确总上市天数。

行业与行业内成交额排名的前X%按总数向上取整换算为名次，并列使用竞赛排名；报告同时保存配置百分比和实际名次门槛。比较方式由服务器按指标白名单校验，整数项、比例范围、二元核验项均严格检查，不执行任意公式或用户代码。

数据缺失继续为待核验；未选条件为不适用；前置层不通过则后续未进入。公告仅标题与窗口目录核验，不是全面风险审查。旧的MA20乖离率、20期均额附加字段保留兼容；新库分别使用R4、R2。

策略JSON保存`five_rules`（id/operator/value）、补充指标、版本和配置指纹；报告冻结所选规则、指标库指纹、实际值、目标门槛和原始数据来源。旧策略没有`five_rules`字段时仍按原24项默认逻辑执行，不改写旧版本。

验收：80项自动化测试通过；每一层各有改变阈值/取消选择影响入选的集成测试。浏览器在独立临时数据目录中验证跨层选择、阈值编辑、V1/V2保存与载回。没有在主库保存验收策略或新增行情任务。
