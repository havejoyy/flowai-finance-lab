# 独立本地版：策略模板与五层可视化报告

2026-10-29，用户已选择 A：独立本地版、按需自动获取行情。延续“暂不调用真实模型”。本轮实现据此推进，不依赖 microApp 服务或数据库，不需要用户另行安装数据库；使用随应用管理的本地 SQLite，也不依赖作者持续更新。

## 范围与体验
一个纵向滚动页面：放量走强 / 弱转强观察 / 板块共振模板 → 可选自定义参数和本地保存版本 → 使用游资股票筛选 Skill → 同页市场、行业、候选、五层证据报告。无分页，候选详情原位展开；可导出完整 JSON 并回查历史。

复用 JoyWorkflow 的本地 HTTP、SQLite、写锁、Host/Origin 校验和固定五层 Skill 资源。现有手动资料页保留为高级入口。frontend-design 用于单页实现：冷灰背景、海军蓝文字、蓝色动作、青绿色证据状态、琥珀色缺口；系统中文无衬线、数字等宽。特色是五层证据横带，每个状态有文字说明，不用雷达分数伪装证据。

## 数据与计算契约
- 无密钥 HTTPS 东方财富公开行情接口：沪深 A 股快照（不含北交所），分页取得完整证券列表，去重并校验 total；取得各股时间戳。运行时间与行情日期分开记录。
- 只支持收盘后快照。盘中不把动态数据冒充收盘，返回明确提示；历史记录可回看，不用今日证券范围回推历史回测。
- 排除 ST、退市标记、无有效价格或成交额；过旧证券行保留缺失计数，不计入当日涨跌统计。市场统计只代表取得的沪深范围，涨跌停制度与炸板率不靠固定涨幅伪造。
- 行业按行情接口当前分类，使用同日成分等权涨幅与上涨占比；不称为题材主线，也不由一天数据确认持续性。
- 先执行可由快照判断的条件，再按成交额降序取最多 120 只做历史核验（默认 40）；截断时报告明确展示未核验数，不能称为全市场最终筛选。用户可调整核验上限，不隐藏抽样。
- 自动获取候选截至快照日期的前复权日 K（至少 60 个观测），计算均线、20 期收益、前五个观测日成交额均值（不包含当日）、今日/前日涨幅。数据缺失、日期不匹配、重复日期、非有限数值都不能补零。
- 历史涨停不使用 9.8% 的跨市场近似条件；首版模板不要求“涨停基因”，报告明确这不是原平台 trader_mentor 的逐字复制。
- 模板是未做收益验证的研究条件，不是知名游资策略或收益预测。模板保存完整参数与版本，不允许用户输入可执行代码。

## 报告
行情来源/日期/取数时间/覆盖度 → 市场涨跌分布 → 行业强弱条形图 → 筛选计数（排除/待核验/通过） → 候选条件与可核对数值 → 五层状态与缺口。
五层为市场环境、主线板块、代表性标的、交易设想证据、风险纪律。第四层只核对用户所选研究条件，不编造个人交易计划；无个人行为资料时明确不适用。五层状态遵循原 Skill：证据充分、证据不足、不通过。
本轮确定性代码生成报告，无模型调用；报告保存 Skill 两份文档及 hash，显示“规则计算，未启用 AI”。不将固定代码模板伪装为 LLM 分析。后续真实模型接入需另外测试，现有高级页面保留显式外发确认。

## 失败与留档
网络超时有界，列表不完整则运行失败；部分历史失败产生带覆盖说明的部分报告，不把缺失当作不符合。重启未完成任务标为 INTERRUPTED，不自动重跑。没有静默旧缓存回退，真实取数失败绝不展示演示数据代替。运行输入、策略版本、原始快照/日 K、接口地址与获取时间、结果一并留档。请求标识防重复提交。

## 验收与交付
测试参数边界、缺失/过期/重复日期、前五日均值、三模板差异、分页与截断、断网、重启、幂等和报告引用；跑一次真实公开数据，不调用模型；真实源失败保留失败证据。浏览器检查模板切换、自定义、运行和报告的单页呈现。打包源码、说明、Skill、虚构样例与测试，不包含真实行情缓存、密钥或用户数据库。外部发布和付费分发尚不在本轮范围。

## 可执行模板与默认值（规则版本 screen-v1）
所有模板先排除 ST/退市标记及无同日收盘证据的行；快照成交额≥0.5亿元；历史核验共同要求前复权收盘价>20期均线>60期均线。20期收益=最新前复权收盘价/第21个倒数收盘价-1。成交倍数=当日成交额/此前五个有效日K成交额均值；不包含当日。均线均含当前观测。

| 模板 | 快照预筛 | 历史核验附加条件 |
|---|---|---|
| 放量走强 | 当日涨幅≥1% | 成交倍数≥2 |
| 弱转强观察 | 当日涨幅≥5% | 成交倍数≥1.2，前一日涨幅≤3% |
| 板块共振 | 当日涨幅≥0%，行业上涨占比≥60%，行业等权涨幅排位在前35%（向上取整，至少1个行业），行业等权涨幅高于市场等权均值 | 成交倍数≥1 |

以上为未做收益验证的产品示例参数。可调范围：成交额0.1–100亿元、当日涨幅-10%–30%、成交倍数0.5–10、前日涨幅-10%–10%、行业上涨占比0%–100%、行业排位1%–100%、历史核验数10–120（整数）。与当前模板无关的参数不展示且不参与该模板条件。缺必需字段进入待核验，不当作条件失败。

## 来源与时点细则
只读探测已取得两个接口的真实响应（2026-10-29）：
- `https://push2.eastmoney.com/api/qt/clist/get`：pn/pz分页，total必须稳定、代码不得重复且总数必须齐；f12代码、f13市场、f14名称、f2收盘价、f3百分比涨幅、f6元成交额、f8百分比换手、f100行业、f124秒时间戳。
- `https://push2his.eastmoney.com/api/qt/stock/kline/get`：klt=101/fqt=1，end=快照日期，lmt=90；f51日期/f53收盘/f57元成交额/f59涨幅，代码/日期/数值校验。前复权收盘值不直接与未复权快照价格比较；同日涨幅误差>0.15个百分点或成交额误差>3%则列为冲突待核验。
- 上海时区；报告日期为有效时间戳中的最大日期。该日期是今天且当前早于15:15时拒绝；任何证券须同日且其时间戳≥15:00才参加计算。周末/节假日可使用来源保留的最近收盘快照，实际日期始终显示；没有交易日历，不宣称已经验证为“最近交易日”。整体快照超过7个自然日拒绝。
- 不允许网络重定向、响应超过4MB、无界重试；历史最多4并发。接口可用性仅代表本次技术验证，不保证持续服务或商业再分发授权。

## 五层状态细则
第一层：取得市场统计但未接全部情绪证据，证据不足。第二层：展示行业分布，持续主线仍证据不足。第三层：给出候选相对数据，代表性/带动性仍证据不足。第四层状态仅指所选研究条件：仍有历史待核验/截断则证据不足；已全部核验且有满足者则对数值条件证据充分；已全部核验且无人满足则不通过。第五层：尚缺公告与长期风险证据，证据不足。个人交易计划/行为的“不适用”写在独立 applicability 字段，不引入第四种状态。
