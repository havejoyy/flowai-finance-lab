# JoyWorkflow 源码更新

## 0.5.2 双平台桌面版

Windows x64 和 Mac Apple Silicon 使用同一版本，均包含独立行情更新按钮、筛选范围统计和缺失原因。

## 2026-11-05：独立更新数据与报告范围说明

- 本地数据页新增“获取最新数据”。重新联网获取公开收盘快照与行业分类，校验后保存 SQLite，显示进度、实际行情日期与缺失原因。
- 更新任务独立留档，刷新页面可恢复查看；运行中防重复提交，服务重启将未完成任务标记为中断。个股历史日 K 和其他五层资料仍在筛选时按需补齐。
- 报告分别显示来源证券数、基础排除数、同日有效证券数、存在数据缺口的股票数及最终入选数。缺口按代码合并并列出具体原因，公共资料缺口与未核验范围单列。
- 历史报告回看及完整导出共用同一展示口径，原报告和数据不改写。

验证：本地 100 项测试通过。浏览器从空库点击更新，实际获取 2026-11-05 的 5,222 条来源行情；3 只报价无效、1 只行业分类缺口明确显示为部分完成，未生成筛选报告。历史报告回看验证了 5,221 来源、234 排除、4,984 有效、5 只缺口、2 只入选的分别展示。

本次发布源码及文档，既有 Windows 0.5.1 和 Mac 0.5.0 下载包不包含以上更新。源码运行步骤见 [README](../README.md#从源码运行)；安装说明见 [桌面应用使用说明](桌面应用使用说明.md)。
