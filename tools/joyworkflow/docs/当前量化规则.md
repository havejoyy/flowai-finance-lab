# 当前已实现的量化筛选条件

日期：2026-10-31。以screening.py的PRESETS、metrics和analyze为准；原youzi-market-research Skill是五层研究框架，下面是独立工具已实现的数值规则。

以下前三个旧模板共同条件：排除名称带ST或退市标记的证券；同日有效收盘行情，至少60条有效日K；前复权收盘价 > MA20 > MA60。

| 内置模板 | 成交额下限（亿元） | 当日涨幅下限 | 成交额倍数 | 额外条件 |
|---|---|---|---|---|
| 放量走强 | 0.5 | 1% | ≥ 2 | 无 |
| 弱转强观察 | 0.5 | 5% | ≥ 1.2 | 前一日涨幅 ≤ 3%（不要求前一日为负） |
| 板块共振 | 0.5 | 0% | ≥ 1 | 行业上涨占比 ≥ 60%；行业等权涨幅排名前35%（向上取整）；行业等权涨幅高于同口径市场等权均值 |

成交额倍数 = 当日成交额 ÷ 此前5条有效日K成交额均值，不包含当日，也不是行情软件的股数“量比”。MA20/MA60为前复权收盘价最近20/60条有效日K的简单均值。

行业上涨占比 = 同日有效成员中涨幅>0的数量 ÷ 有效成员数。行业与市场涨幅均按各自有效证券范围等权计算。行业使用申万当前一级分类，不等于题材主线。

默认按成交额排序，对最多40只初筛候选核验历史，可改为10至120只；这是计算覆盖上限，不是选股质量指标。20期价格变化为报告展示指标，不参与入选判断。缺少数据单列待核验，不视作条件不通过。

前三个旧模板未完整量化接入：涨跌停及炸板率、连板梯队、昨日强势反馈、题材事件和持续性、龙头带动性、公司公告、个人行为与纪律；不能把当前3套规则当作完整五层模型。

页面修正：运行摘要和数据进度仅在筛选结果页显示；我的策略同时展示全部内置模板及全部保存版本。保存版本数由SQLite实时读取。

浏览器验证：3个内置模板、3个已保存版本均展示；载入V2参数正确。回看已有真实报告后，本地数据/我的策略/策略筛选/历史记录四页的运行提示均不可见。59项回归测试通过，未发起新模型调用或行情筛选。

## 新增第四个策略：游资五层共振·放量突破 V1

生效定义：[JSON](../strategies/youzi-five-layer-breakout-v1.json)，计算器`five_layer.py`；规则版本`youzi-five-layer-v1.0.0`。原始五层Skill作为研究框架保留不变，本策略将其中可公开取数的部分转成量化代理。

| 层级 | 默认适用硬规则 |
|---|---|
| 1 市场环境 | 合资格行情覆盖≥98%、实际限价覆盖≥98%；上涨占比≥40%、跌停占比≤1%、炸板率≤45%、昨日涨停股今日涨幅中位数≥−1%；日历/名录/基准资料可用 |
| 2 行业共振代理 | 申万一级行业同日等权涨幅排名前20%（向上取整）、上涨占比≥55%、实际涨停≥2只、行业指数5日表现超过沪深300≥1个百分点、5日中至少3日上涨；成员≥10、行业行情覆盖≥95% |
| 3 行业内活跃代表 | 成交额≥2亿元且行业内排名前20%；5日表现超过行业指数≥2个百分点；收盘>MA20>MA60；当日涨幅/经实际上下限校验的适用涨幅限制≥0.30 |
| 4 放量突破 | 收盘突破此前20交易日最高价（不含当日）；成交额/此前5日均额≥1.5；收盘位置(C−L)/(H−L)≥0.70，H=L不通过 |
| 5 风险约束 | 上市≥120交易日、20日均额≥1亿元、(ATR14/收盘)/适用涨幅限制≤0.50、相对MA20乖离≤12%、非一字行情；最近5交易日起的公告标题目录完整且无待复核命中 |

ATR14采用14个真实波幅的简单均值。收盘/均线/历史高低价沿用同一前复权口径；当前实际限价统计使用未复权当日报价，不使用固定9.9%代替涨停。公告窗口到本次信息截止时间，时间未知或关键词命中单列待核验，不能自动认定无风险。

默认核验上限120只，按成交额排序，超过上限保留为“未核验”。前置层不通过则后续层“未进入”，所需数据不可得为“待核验”；只有全部适用硬规则通过才入选。通过集合内排序权重：行业相对表现30%、个股相对行业30%、成交额倍数20%、收盘位置20%；单只通过时不输出分位排名分数。分数不是上涨概率。

行业联动不等于真实题材主线，成交活跃代表不等于已确认龙头；个人计划、账户仓位及交易纪律没有输入，标为不适用。新策略仅接入公开数据代理，没有接入游资身份、题材事件因果或真实模型推理。
