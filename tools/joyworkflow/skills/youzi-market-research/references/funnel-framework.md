# 五层漏斗输入与输出

## 最小输入表

```text
交易日期与截止时间：
数据来源：

1. 市场：上涨__家，下跌__家，涨停__家，跌停__家，炸板率__，成交额__亿元。
2. 板块：候选板块__，驱动__，活跃天数__，涨停或显著上涨__家，梯队__。
3. 标的：名称/代码__，板块地位证据__，成交与价格行为__，流动性__。
4. 设想：用户原计划__，触发条件__，失效条件__，信息来源__。
5. 风险：事件风险__，波动与流动性风险__，计划偏离风险__。
```

## 状态定义

- **证据充分**：用户提供的数据足以支持当前层的观察性判断，同时已检查明显反证。
- **证据不足**：关键字段缺失、数据过时、来源不明或证据相互冲突。
- **不通过**：已有可核验事实直接否定用户为该层设定的条件。

“证据充分”只表示资料足以研究，不代表值得买入或未来会上涨。

## 输出模板

对每一层输出：

```text
状态：证据充分 / 证据不足 / 不通过
支持证据：
反证与替代解释：
缺失数据：
下一步可核验事项：
```

最后汇总：

1. 当前资料能支持的观察结论。
2. 最可能推翻该结论的三项事实。
3. 仍需补充的数据及来源。
4. 用户原计划中可能存在的追涨、确认偏误、幸存者偏差或权威偏误。

不得将汇总转换成买卖、仓位、目标价或止损价建议。
