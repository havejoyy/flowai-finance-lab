# 六步解读字段与模板

## 最小输入

- 交易日期与数据截止时间
- 上榜个股名称、代码
- 上榜原因（日涨幅偏离值/日振幅/连续累计）
- 涨跌幅、换手率、收盘价
- 买入前五席位名称、金额
- 卖出前五席位名称、金额
- 同板块其他上榜股（可选）
- 用户关注的观察问题（可选）

### 6. 板块联动

| 指标 | 内容 |
|---|---|
| 同板块上榜股 |  |
| 席位是否重叠 | □是 □否 □信息不足 |
| 联动类型 | □题材集体 □个股独立 □信息不足 |
| 板块资金强度 | □强 □中 □弱 □信息不足 |

集体行动和单打独斗，操作策略完全不同。

### 7. 下一交易日观察清单

最多列三种情形。每种情形写明：需要观察的事实、确认信号、失效信号、仍缺数据。不要分配概率或仓位，除非用户只是在回顾自己已经制定的规则。

## 质量检查

- 席位身份是否有来源？
- 结论是否混淆事实与推断？
- 是否遗漏反证或数据缺口？
- 是否出现个性化买卖、仓位或收益承诺？
- 是否把龙虎榜滞后数据当作确定性未来走势？
