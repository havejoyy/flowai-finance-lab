# 龙虎榜六步输出框架

## 最小输入

- 交易日期、来源、抓取时间和完整性
- 股票名称、代码、上榜原因、涨跌幅、换手率、收盘价
- 按 `TRADE_ID` 区分的买卖前五席位及金额
- 市场环境、同板块股票、分时封板、前五日成交量（交叉验证所需；可缺失）

## 1. 数据说明

列明日期、来源、截止时间、股票数、上榜记录数、缺失席位、错误和统计口径。同股多原因不得重复累计为全市场净额。

## 2. 上榜定位

| 指标 | 当日数据 | 解释 |
|---|---:|---|
| 上榜原因 |  | 只解释披露触发条件 |
| 涨跌幅 |  | 不统一把9.9%称为涨停 |
| 换手率 |  | 结合板块规则描述分歧 |
| 收盘价 |  |  |

- 涨幅偏离：价格相对基准显著走强，不单独证明主动拉升。
- 振幅：价格波动较大，通常反映分歧，但需成交路径验证。
- 连续累计：过去数日价格具有连续性，不代表未来延续。

## 3. 席位画像与市场映射

逐席位输出：

| 方向 | 排名 | 席位 | 买入/卖出/净额 | 属性 | 认知标签 | 证据等级 |
|---|---:|---|---:|---|---|---|

证据等级只允许：

- `事实`：接口直接返回的席位名称与金额。
- `市场认知`：匹配参考映射，但未经官方确认。
- `信息不足`：无法核验身份或风格。

## 4. 买卖拆解与结构定性

计算：

- 买卖前五合计、净额和最大买方占前五买入比例。
- 最大买方金额占当日市场成交额比例。
- 机构专用买卖金额及净额。
- 买卖榜同名席位重叠数。
- 已映射市场认知席位数量。

结构标签允许多选，严格按 [席位映射与结构规则](seat-mapping-and-signals.md) 判定。若必要字段缺失，输出“结构信息不足”。

## 5. 五层框架交叉验证

| 层级 | 状态 | 必要证据 | 反证/缺失 |
|---|---|---|---|
| 市场环境 | 证据充分/证据不足/不通过 | 涨跌家数、涨跌幅分布、成交环境 |  |
| 主线板块 | 证据充分/证据不足/不通过 | 驱动、板块梯队、持续时间 |  |
| 代表性地位 | 证据充分/证据不足/不通过 | 板块领先性、带动性、封板路径 |  |
| 量价与节点 | 证据充分/证据不足/不通过 | 前5日均量、前高、连板高度、分时 |  |
| 风险纪律 | 证据充分/证据不足/不通过 | 流动性、集中度、事件与信息滞后 |  |

量能“三倍量”、最先封板、带动≥5家、高位7板等只作为待核验观察维度；没有对应数据时不得推断。

研究适配度：

- `A`：至少4层证据充分，且主线、代表性、风险纪律没有“不通过”。
- `B`：2至3层证据充分，或存在一个非关键层不通过。
- `C`：主线、代表性或风险纪律任一不通过，或不足以形成至少2层充分证据。

必须写明“A/B/C为研究证据适配度，不是交易评级”。

## 6. 行为信号卡

| 信号 | 客观观察条件 | 数据状态 |
|---|---|---|
| 超预期 | 次日竞价高开>3%，且竞价成交额约为前一日成交额5%-10%；或开盘15分钟内封板且封单>1亿元 | 待次日验证 |
| 符合预期 | 次日在前收盘价±2%内缩量震荡，完整席位中的主要资金没有可观察到的集中反向信号 | 待次日验证 |
| 不及预期 | 次日低开超过3%且前15分钟未翻红；或急拉后放量跌破分时均线 | 待次日验证 |
| 集中度风险 | 最大买方占前五买入≥50%，或占全天成交≥10%；历史持有周期若无可核验数据则标记不足 | 当日可算/历史不足 |

这些阈值是研究启发式，不保证适用于所有价格限制、流动性和市值环境。

## 7. 板块联动与资金协同

| 指标 | 内容 |
|---|---|
| 同板块上榜股 |  |
| 席位是否重叠 | 是/否/信息不足 |
| 联动类型 | 题材集体/个股独立/信息不足 |
| 资金协同 | 多股同向/双边交易/信息不足 |

同一席位跨股出现只证明通道重叠；“围点打援”只能作为待验证假设，不能作为事实。

## 质量检查

- 是否按 `TRADE_ID` 保留多原因口径？
- 是否把市场传闻误写成自然人归属事实？
- 是否把金额阈值误写成机构真伪？
- 是否把双边席位直接判定为量化对倒？
- 五层状态是否有数据支撑？
- A/B/C是否明确为研究适配度？
- 信号卡是否写成待验证条件，而非交易指令？
- 是否遗漏反证、缺口和滞后风险？
