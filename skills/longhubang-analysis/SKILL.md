# 龙虎榜解读

把公开的龙虎榜数据翻译成可追溯的六步席位解读。只依据用户提供或可核验的数据工作；缺失项标记为"信息不足"，不得补造席位行为或当日行情。

## 数据入口与自动获取

只依据以下两类输入工作：

1. 用户提供的龙虎榜原始数据；
2. 本 Skill 的 `scripts/fetch_longhubang.py` 从东方财富公开接口取得的可核验数据。

当用户给出交易日期但没有提供原始数据时，必须先获取数据再分析：

1. 以本 `SKILL.md` 所在目录作为 Skill 根目录，不假设当前工作目录是 GitHub 仓库。
2. 在 Skill 根目录执行 `python3 scripts/fetch_longhubang.py YYYY-MM-DD --json`；默认获取汇总及买卖前五席位。
3. 仅在命令成功且 JSON 非空时继续六步解读。
4. 在数据说明中列明交易日期、来源、抓取时间和缺失字段。

脚本随 Skill 一起安装，纯 Python 标准库实现，无需第三方包：

```bash
# 获取当日龙虎榜数据，输出 Markdown（默认）
python3 scripts/fetch_longhubang.py 2026-08-07

# 保存到文件
python3 scripts/fetch_longhubang.py 2026-08-07 > lhb-2026-08-07.md

# 输出 JSON 格式
python3 scripts/fetch_longhubang.py 2026-08-07 --json > lhb-2026-08-07.json

# 外部接口压力较大时仅取汇总
python3 scripts/fetch_longhubang.py 2026-08-07 --summary-only --json
```

数据来源：东方财富数据中心公开 API。脚本使用 `RPT_DAILYBILLBOARD_DETAILSNEW` 获取当日汇总，并使用 `RPT_BILLBOARD_DAILYDETAILSBUY`、`RPT_BILLBOARD_DAILYDETAILSSELL` 获取买卖席位。全程只用 Python 标准库。

同一股票存在多个上榜原因时，必须以 `TRADE_ID` 分组，分别保留金额和席位，不能按股票代码合并金额。脚本输出的 `complete`、`incomplete_ranking_count` 和 `errors` 用于判断数据是否完整。

### 失败与降级

- 日期格式错误：指出格式必须为 `YYYY-MM-DD`，不自行猜测日期。
- 无数据：说明可能是非交易日、数据尚未发布或数据源无记录，不生成当日事实结论。
- 网络或 API 失败：报告真实错误并建议稍后重试或由用户提供数据，不补造结果。
- `complete=false`：只分析已完整返回的上榜记录；缺失记录标记“信息不足”。
- `--summary-only`：只分析上榜定位和金额结构；席位身份、买卖前五、席位重叠和历史风格统一标记“信息不足”。
- 不把东方财富的历史“成功率”字段解释为未来概率。
- 不把营业部名称直接等同于某位游资；身份必须另有可核验来源。

## 执行顺序

1. **确认上榜定位**：记录交易日期、上榜原因（日涨幅偏离值/日振幅/连续累计）、涨跌幅、换手率。不同触发原因含义不同，不得混为一谈。
2. **席位画像**：对买卖前五每个席位标注属性——知名游资（给出风格画像：一日游/趋势/接力）、机构专用（区分真建仓 vs 调仓）、量化席位（区分对冲 vs 方向性押注）、普通营业部。席位身份无法核验时标记"信息不足"，不臆测。
3. **买卖拆解**：拆解买入前五和卖出前五的席位结构与金额，区分游资真买入（买方全是游资席位）、量化对冲（买卖都有量化席位）、机构调仓（机构在买卖两边都出现）。不把净买入等同于利好。
4. **意图推演**：基于席位可核验的历史行为模式，给出次日可能性（接力/出货/锁仓/无法判断）。区分"基于历史行为的概率"与"对未来的预测"，不输出精确概率或确定性结论。
5. **板块联动**：关联同板块其他上榜股，判断是题材集体资金介入（板块机会）还是个股独立行情。同板块多只上榜股的席位是否重叠也需要检查。
6. **形成观察条件**：写出下一交易日需要验证的情形、触发信号和失效信号，只给观察条件，不给仓位、买卖点或收益预测。

详细字段和输出模板见 [references/longhubang-framework.md](references/longhubang-framework.md)。

## 数据与推理规则

- 对席位历史行为优先调用可核验数据；无法访问时要求用户提供，不编造席位风格。
- 每个结论分别标注"事实""推断"或"信息不足"。
- 所有金额写明单位和统计口径，例如"万元""净买入"。
- 对席位意图等推断列出至少两项支持证据，并给出反证或不确定性。
- 不根据不完整数据填写不存在的精确概率。
- 不输出"可以买入""应卖出""仓位几成""目标价"等个性化交易指令。
- 龙虎榜是滞后数据，仅反映当日已发生的事实，不得推导为确定性未来走势。

## 输出结构

依次输出：数据说明、上榜定位、席位画像、买卖拆解、意图推演、板块联动、下一交易日观察清单、数据缺口与风险提示。

结尾固定说明：

> 本解读仅用于信息整理和学习研究，不构成投资建议、收益承诺或任何交易指令。龙虎榜为滞后数据，席位行为不代表未来走势。市场有风险，决策需独立核验。
