# 龙虎榜战术解读

把公开龙虎榜翻译成可追溯的六步席位解读，并与五层游资市场研究框架交叉验证。只依据用户提供或可核验的数据工作；缺失项标记“信息不足”，不得补造席位身份、板块地位或行情。

## 数据入口与自动获取

只依据用户提供的数据或本 Skill 脚本取得的数据工作。用户只给交易日期时：

1. 以本 `SKILL.md` 所在目录为 Skill 根目录。
2. 执行 `python3 scripts/fetch_longhubang.py YYYY-MM-DD --json`，默认获取汇总及买卖前五。
3. 仅在命令成功且 JSON 非空时分析。
4. 列明日期、来源、抓取时间、`complete`、`incomplete_ranking_count` 和 `errors`。

```bash
# 完整汇总及买卖前五，默认 Markdown
python3 scripts/fetch_longhubang.py 2026-08-10

# 完整 JSON
python3 scripts/fetch_longhubang.py 2026-08-10 --json

# 数据源压力较大时仅取汇总
python3 scripts/fetch_longhubang.py 2026-08-10 --summary-only --json
```

脚本只用 Python 标准库。它通过东方财富公开接口获取当日汇总和买卖席位，并按 `TRADE_ID` 保留同股不同上榜原因的独立金额口径。

失败或降级时：

- 日期、网络或API错误：报告真实错误，不生成当日事实结论。
- `complete=false`：只分析完整记录，受影响记录标记“信息不足”。
- `--summary-only`：不做席位映射、席位重叠或历史风格判断。

## 六步法

1. **确认上榜定位**：区分涨幅偏离、振幅、换手和连续累计；记录涨跌幅、换手率、收盘价。触发条件是事实，不直接解释为资金意图。
2. **席位画像与市场映射**：读取 [席位映射与结构规则](references/seat-mapping-and-signals.md)，对买卖前五逐项标注“事实/市场认知/信息不足”。严禁把营业部确定归属于自然人。
3. **买卖拆解与结构定性**：计算席位金额、占比、双边重叠和机构净额；按参考文件标注“合力特征/一家独大/大额机构净流入/散户接力特征/双边交易特征/混合”。标签描述结构，不证明真实意图。
4. **五层框架交叉验证**：依次检查市场环境、主线板块、代表性地位、量价与节点、风险纪律。每层只用“证据充分/证据不足/不通过”；读取不到板块、分时、封板或前五日量能时必须标记不足。
5. **行为信号卡**：输出次日可核验的超预期、符合预期、不及预期和风险条件，不预测哪种情形一定发生。
6. **板块联动与资金协同**：检查同板块上榜股和席位重叠；没有行业/概念字段时不得仅凭股票名称猜测板块。

- [席位映射与结构规则](references/seat-mapping-and-signals.md)

## 推理与安全规则

- 每个结论标注“事实”“市场认知”“推断”或“信息不足”。
- 市场席位映射属于未获官方证实的常用说法，必须逐席位提示并允许一席多主体。
- “机构专用”金额只能分为大额、小额或双边记录，不能称“真机构”“假机构”。
- 华鑫、外资券商或总部席位出现在买卖两边，只能标记“双边交易特征”，不能直接断言量化对倒。
- 东方财富的历史“成功率”不等于未来概率，不纳入预测。
- 结构推断至少列两项证据，并给出反证或缺失数据。
- A/B/C仅表示五层证据适配度，不是股票评级：A=多数层证据充分且无关键层不通过；B=证据混合；C=关键层不通过或多数层不足。
- 不输出“可以买入”“应卖出”“仓位几成”“目标价”或收益预测。

## 强制输出结构

1. 数据说明
2. 上榜定位
3. 席位画像与市场映射
4. 买卖拆解与结构定性
5. 五层框架交叉验证与A/B/C研究适配度
6. 次日行为信号卡
7. 板块联动与资金协同
8. 数据缺口与风险提示

结尾固定说明：

> 本解读仅用于信息整理和学习研究，不构成投资建议、收益承诺或任何交易指令。龙虎榜为滞后数据，席位行为不代表未来走势。席位与游资的映射基于公开市场传闻，未经官方证实，需投资者独立核验。市场有风险，决策需谨慎。
