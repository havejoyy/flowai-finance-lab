# A股股性分析

“股性”不是玄学标签，而是一只股票在特定观察窗口内反复呈现的价格和成交行为。本 Skill 输出多维画像，不把股票永久定性为“活跃”“妖”或“庄”。

## 开箱使用

用户只给股票代码时，以本 `SKILL.md` 所在目录为根目录运行：

```bash
python3 scripts/analyze_stock_character.py 600519 --json
```

默认从东方财富公开行情接口获取截至最近交易日的前120根前复权日线。用户指定截止日期时：

```bash
python3 scripts/analyze_stock_character.py 600519 --end 2026-09-04 --json
```

也可以读取本地日线 CSV：

```bash
python3 scripts/analyze_stock_character.py --input daily.csv --json
```

本地字段至少包括 `date/open/close/high/low/volume/amount`，可选 `turnover_rate`。网络或字段不完整时报告真实错误，不生成股性结论。

## 五维股性

1. **波动**：20日年化波动率、ATR占价格比例、日均振幅、大涨跌频率。
2. **趋势**：20日收益、方向效率、均线方向；区分趋势推进和来回震荡。
3. **流动性**：成交额中位数、成交额稳定性和换手率。流动性表示能否较快成交且不显著冲击价格，不等于股票质量。
4. **活跃度**：跳空频率、大幅波动频率、换手活跃度；不能据此推断资金操纵或具体主体意图。
5. **回撤恢复**：60日最大回撤、从局部低点恢复的速度和当前距区间高点距离。

指标口径、阈值与标签见 [股性框架](references/stock-character-framework.md)。阈值是研究用默认值，需结合市场制度、板块和样本分布解释。

## 标签规则

标签允许并存：`稳定趋势`、`高波动趋势`、`低波动震荡`、`高频脉冲`、`高弹性`、`流动性偏弱`。每个标签必须同时给出：

- 支持指标；
- 观察窗口和截止日期；
- 反证或失效条件；
- 数据完整度。

若没有标签达到条件，输出“混合型/暂不定型”，不得强行归类。股性会随题材、流动性和市场阶段变化，历史窗口结论不得外推为永久属性。

## 强制输出

1. 数据说明：代码、名称、日期、来源、复权口径、样本数
2. 五维雷达：每维核心指标、证据和解释
3. 当前股性标签及反证
4. 持有难点：这种波动结构容易诱发什么执行问题
5. 与个人交易记录联动时需要检查的字段
6. 数据缺口与风险提示

不输出“适合买入”“应卖出”“目标价”“止损价”“仓位几成”。结尾固定说明：

> 本分析描述历史价格与成交行为，不构成股票质量评价、投资建议、个性化交易指令或收益预测。股性会随观察窗口和市场环境改变，请独立核验数据。
