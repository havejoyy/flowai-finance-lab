# 股性分析框架

## 为什么采用多维分类

“活跃股、趋势股、妖股、庄股”常混合了价格事实、行情阶段和无法验证的资金意图。可复核的股性应拆为波动、趋势、流动性、活跃度、回撤恢复五个维度，再生成允许重叠的场景标签。

## 默认指标

| 维度 | 指标 | 默认窗口 | 含义 |
|---|---|---:|---|
| 波动 | 日收益年化波动率 | 20日 | 收盘价格变化速度 |
| 波动 | ATR/收盘价 | 14日 | 包含跳空后的日常波动范围 |
| 波动 | 平均振幅 | 20日 | 盘中价格活动范围 |
| 趋势 | 方向效率 ER | 20日 | 净位移÷每日绝对位移，越高越单向 |
| 趋势 | 区间收益 | 20日 | 当前方向，不代表未来延续 |
| 流动性 | 成交额中位数 | 20日 | 成交容量代理，不等于真实市场深度 |
| 流动性 | 成交额变异系数 | 20日 | 交易活跃是否稳定 |
| 活跃度 | 绝对涨跌≥7%天数占比 | 60日 | 大幅波动出现频率 |
| 活跃度 | 绝对跳空≥2%天数占比 | 60日 | 隔夜信息敏感度代理 |
| 回撤 | 最大回撤 | 60日 | 窗口内从高点到低点的最大跌幅 |
| 回撤 | 距60日高点 | 60日 | 当前相对近期峰值的位置 |

## 默认标签

这些阈值用于生成稳定、可重复的初步标签，不是市场定律：

- **稳定趋势**：方向效率≥0.45、20日绝对收益≥8%、年化波动率<45%。
- **高波动趋势**：方向效率≥0.45、20日绝对收益≥8%、年化波动率≥45%。
- **低波动震荡**：方向效率≤0.25、年化波动率≤25%。
- **高频脉冲**：60日大幅波动频率≥10%，且方向效率<0.45。
- **高弹性**：年化波动率≥45%或20日平均振幅≥5%。
- **流动性偏弱**：20日成交额中位数<1亿元。成交金额不是盘口深度，结论必须标记为代理指标。

阈值附近的标的应标记“临界”，避免小数点差异造成武断分类。不同板块涨跌幅制度不同，大幅波动频率只描述实际波动，不把7%称作涨停或跌停。

## 与个人行为联动

股性分析本身不回答“适合谁”。联动 `trading-personality-fit` 时，比较用户真实持有过的不同环境：

- 高波动中是否更容易追涨、临时加仓或提前卖出；
- 趋势环境是否能持有到计划条件，还是频繁交易损耗收益；
- 震荡环境是否出现反复止损和连续亏损；
- 最大不利波动是否超过用户历史可承受范围；
- 流动性偏弱环境是否出现成交困难或异常滑点。

只说“历史执行摩擦较低/较高”，不把历史收益包装成未来适配或荐股结论。
