# 财报分析框架

## 报告身份

先记录公司、代码、报告期、报表口径、币种、单位、审计机构和审计意见。修订版报告应标记修订日期。

## 核心指标

| 主题 | 指标 | 重点检查 |
|---|---|---|
| 增长 | 营业收入、归母净利润、扣非净利润 | 增速是否一致，增长是否依赖非经常项目 |
| 盈利 | 毛利率、营业利润率、净利率、ROE | 趋势、行业差异、利润率背离 |
| 营运 | 应收、合同资产、存货、预付款 | 增速是否显著高于收入，减值是否充分 |
| 偿债 | 货币资金、有息负债、短期债务 | 现金是否受限，短债与可用现金是否匹配 |
| 现金流 | 经营现金流、资本开支、筹资现金流 | 经营现金流与利润是否匹配，扩张是否依赖融资 |
| 治理 | 关联交易、担保、诉讼、审计意见 | 是否存在利益输送、或有损失或披露异常 |

## 常用计算

- 同比增速 =（本期值 − 上期值）÷ 上期值。上期为零或正负号跨越时不要给误导性百分比。
- 毛利率 =（营业收入 − 营业成本）÷ 营业收入。
- 经营现金含量 = 经营活动现金流净额 ÷ 归母净利润。净利润接近零或为负时改用绝对差额解释。
- 应收增速与存货增速应和收入增速并列比较，不用单一阈值直接定性。
- 有息负债需结合短长期结构、受限资金、利息费用和到期安排判断。

## 重点异常信号

- 收入增长而经营现金流持续恶化。
- 应收、合同资产或存货增速长期显著高于收入。
- 毛利率改善但净利率下降，或利润主要来自投资收益、公允价值变动、政府补助和资产处置。
- 商誉或长期资产占比较高且出现减值迹象。
- 短期债务压力增加而可自由使用现金不足。
- 频繁变更会计政策、重大前期差错更正、非标准审计意见或关键审计事项恶化。
- 大额关联交易、资金占用、违规担保、重大诉讼或持续经营不确定性。

异常信号只是查证入口，不等同于舞弊结论。

## 红黄绿标准

- **绿**：数据支持且未发现重要反证。
- **黄**：存在恶化、口径变化、证据冲突或信息不足，需要进一步核实。
- **红**：报告已披露重大不利事实，或多项相互印证的风险信号同时出现。

每个颜色必须附原始证据。不得把颜色转换成买卖建议。
