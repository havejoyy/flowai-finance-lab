# 上市公司财报分析

把长篇财报压缩成“结论—证据—不确定性”结构。优先引用原始报告，不用二手解读替代财报事实。

## 执行顺序

1. **确认报告身份**：核对公司全称、证券代码、报告类型、报告期、合并/母公司口径、币种、单位及是否经审计。
2. **建立文档地图**：定位主要会计数据、管理层讨论与分析、三张报表、附注、关联交易、担保诉讼和审计意见。
3. **提取多期数据**：至少比较本期与上期；用户要求趋势时尽量取得连续三期。数字必须带报告期、单位和页码或章节。
4. **分析利润质量**：检查收入、毛利、营业利润、归母净利润、扣非净利润及利润率变化，区分主营经营和非经常性项目。
5. **分析资产负债**：检查应收、存货、商誉、有息负债、受限资产、减值和或有负债。
6. **分析现金流**：比较经营现金流与净利润，检查资本开支、筹资依赖和自由现金流压力。
7. **检查治理与披露**：关注关联交易、资金占用、担保、诉讼、审计意见、会计政策变更和重大期后事项。
8. **形成红黄绿信号**：按成长性、盈利质量、财务韧性、现金流和治理风险输出证据化判断，并列出待核实事项。

指标定义、异常信号和标准输出见 [references/analysis-framework.md](references/analysis-framework.md)。

## 证据规则

- 数字必须来自报告正文、报表或附注，并尽可能给出页码或章节。
- 同时报告绝对值、同比变化和口径变化；无法同比时说明原因。
- 不混用合并报表与母公司报表，不混用亿元、万元和元。
- 发现报表与附注不一致时并列展示，不自行选择“正确值”。
- 无法提取或确认时标记“未核实”，不得估造。
- 将事实、计算结果、推断和风险假设明确分开。

## 输出结构

依次输出：报告身份、执行摘要、关键指标表、利润质量、资产负债、现金流、治理与审计、红黄绿信号、证据索引、待核实清单、局限说明。

结尾固定说明：

> 本分析基于指定报告期的公开披露，仅用于信息整理和学习研究，不构成投资建议、估值结论或交易指令。财务数据和关键判断应回到原始报告复核。
