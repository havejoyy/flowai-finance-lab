# 六因子计算口径（原版与公开版）

原版CN_PANIC_V1移植自 microApp 的 `backend/services/panic_index_calculator.py` 与 `panic_index_methodology.py`（2026-10-17读取）；仅修改模块导入。核心公式版本散列为 `b642169b9476a6290f99bd3e3a06ccd5499421bf993eea87a315e90fb59f58c9`。脚本为计算权威来源。公开版保留这些公式，但版本为CN_PANIC_PUBLIC_V1，使用当前存续股票回看历史，初始化最近400个交易日。具体差异见[公开版说明](public-data.md)，不能与原版分数直接混用。

| 因子 | 原始量 | 分项 |
|---|---|---|
| F1 | 1 − 沪深300当日收盘 / 最近60个交易日（含当日）最高收盘 | 强度 |
| F2 | √(最近10日负收益率平方和 / 10) × √252；非负收益记0 | 强度 |
| F3 | 当日下跌股票数 / 有效当日样本数 | 扩散 |
| F4 | 当日可比收盘低于此前60个交易日最低价的数量 / 有完整61日可比价格的样本数 | 扩散 |
| F5 | 收盘精确等于当日法定跌停价的数量 / 有有效涨跌停规则的样本数 | 抛压 |
| F6 | 跌幅达到当日法定跌停幅度一半及以上的数量 / 有有效涨跌停规则的样本数 | 抛压 |

当日涨跌幅使用原始收盘 / 参考昨收 − 1；F4以复权因子转为当日可比价格。F6分母幅度为 `1 − 跌停价 / 参考昨收`，并非对所有股票统一用5%。不把北交所、CDR、ST、新股和全日停牌样本混入。

## 从原始量到0—100分

每个因子原始值先用 ROUND_HALF_UP 固定到10位小数。参考窗口为当日之前最多756个交易日，排除当日和未来；仅使用相同方法版本、原始状态READY的数据。每个因子至少252个参考日，且从最早有效参考日至前一交易日覆盖≥95%。

原始量为0时记0分；大于0时：

`因子分 = 100 × (历史值小于当日值的个数 + 0.5 × 等于当日值的个数) / 有效参考数`

- 强度分 = (F1分 + F2分) / 2
- 扩散分 = (F3分 + F4分) / 2
- 抛压分 = (F5分 + F6分) / 2
- 总分 = (强度分 + 扩散分 + 抛压分) / 3

中间运算使用40位Decimal精度；输出展示1位小数，保留JSON精确值以供核对。结果校验值排除查询日期，所以同一批数据在不同日期复算仍可比较。

## 数据门槛

当日价格覆盖≥98%，61日历史覆盖≥95%，涨跌停制度覆盖≥99%，跌停价覆盖≥99%；各板块日数据覆盖≥95%，历史/制度/跌停价分别也需达门槛。历史样本缺失不可用删除交易日历的方式掩盖。没有足够数据就没有有效总分。

## 解释范围

高分说明这组价格行为相对历史压力高。强度、扩散、抛压可以不一致，最高一项只代表当前三项的比较；不证明未来上涨或下跌。沪深300偏向大盘；权重、窗口是试验参数。历史回算可能包含供应商事后修订；没有交易预测优势的验证结论。
