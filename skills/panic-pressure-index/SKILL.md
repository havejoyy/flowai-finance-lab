# 恐慌压力指标

默认运行公开数据版：自动下载公开月度行情包 → 原始行情计算六因子 → 历史排名 → 三分项 → 0—100总分。用户不用上传交易记录、不用准备行情、不依赖作者服务器或定期维护数据。

## 一步调用

将 `<skill目录>` 替换为本技能实际绝对路径。使用 Python 3.9+，首次自动创建专用虚拟环境并安装 numpy/h5py（运行环境已有时直接使用）。需要终端执行能力和联网权限。

```bash
python3 <skill目录>/scripts/panic_pressure.py
python3 <skill目录>/scripts/panic_pressure.py --date 2026-09-30 --json
```

无需先问用户要数据目录或配置文件。默认缓存位于 `~/.cache/panic-pressure-index`（支持XDG_CACHE_HOME）。首次下载约1GB、解压占数GB，计算数百个交易日；执行前简短说明下载和初始化，按工具权限处理联网。用 `--cache-dir /path/to/cache` 可指定缓存位置，不是要求用户提供数据。完整流程入口为 `scripts/run_public.py`。

每次在线调用检查上游更新；相同数据包复用校验后的原始因子缓存、重算分数，新包自动下载并重建整批历史。因供应商会修订历史且股票池改变，不能把新旧包增量拼接。这不是每日行情服务：上游公开包按月更新。

## 每次回答必须让用户看懂

- 先给**实际数据日 + 总分 / 100**，再给强度、扩散、抛压。强度看深浅，扩散看范围，抛压看极端。
- 若数据早于查询日，突出历史日期。用户问“今天”而数据未到今天时先说明无法代表今天，不能把下载日期当行情日期。
- 标注 `CN_PANIC_PUBLIC_V1`：使用该数据包中当前存续普通A股回看历史，存在幸存者偏差，不是历史全市场。不能与原 `CN_PANIC_V1` 的66.5分直接比较或拼接。六个原始因子与合成公式保留，股票池和实际参考样本有区别。
- 根据最高分项写一句解释；按需展示原始因子、参考日数、覆盖率和来源。不要把分数当恐慌人数比例、下跌概率或抄底信号。

退出码0且 `status=READY` 才有有效分数。指定日期缺数据、下载失败、损坏或样本不足时，报告错误，不填0、不删减因子。联网失败不会自动拿旧缓存冒充更新成功；若用户接受历史缓存，可显式加 `--offline`，注明未检查更新。正在计算时不要重复启动；进度写stderr，最终结果写stdout。

## 计算及来源

[公开版说明](references/public-data.md)描述数据源、缓存、股票池、首次初始化和限制。详细六因子公式见[计算口径](references/methodology.md)。代码保留Decimal确定性运算，至少252个有效历史参考日，严格排除当日和未来参考；不改变覆盖率门槛。

每次保存审计JSON至缓存中的 `last-result.json`。不要将包含供应商原始行情的缓存提交仓库或随Skill打包。调用不自动发布、交易、建立定时任务、写回microApp或推送仓库。

## 原版复算（仅用户明确需要时）

```bash
python3 <skill目录>/scripts/panic_pressure.py --local --date 2026-09-30
```

这条兼容路径才读取 `config.local.json`，仍需原microApp快照。协议见[本地数据接口](references/data-contract.md)。默认公开模式不读取该配置、不会借用作者电脑路径。仅安装本Skill及Python即可自动启动公开模式。
