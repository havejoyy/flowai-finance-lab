# 财报变化追踪

输入两份官方年报、半年报或季报 PDF；输出 `comparison.json`、`变化清单.md` 和带来源的输入文件。由 Agent 识别表格语义与解释，Python 负责证据片段匹配、口径校验和计算。不是一个无需模型判断的全自动 PDF 表格解析器。

## 运行

以下相对路径命令在本 Skill 目录中运行，或将 scripts/ 改成实际绝对路径。PDF 视觉复核可用现有PDF查看器；若需本地渲染，可选 `pypdfium2`（`python3 -m pip install pypdfium2`），它不是计算脚本的必需依赖。

提取后先抽查公司名称、表头和中文指标。若有文字但明显乱码，不能因字数检查通过就继续：安装上述可选依赖并给提取命令加 `--engine pypdfium2`，重新提取和看原页。仍不可读时标未核实。输出记录实际解析引擎。金额支持元、万元、百万元、亿元。

1. 核对公司、代码、报告类型、起止日期、合并口径、币种、单位、审计情况。默认同公司、相邻年度同类报告；单季与年初至今不能混用。银行、保险等金融公司不使用本版。
2. 用 `python3 scripts/extract_pdf.py OLD.pdf NEW.pdf --output work/sources.json` 提取逐页文本与文件哈希；需要 `pypdf`（`python3 -m pip install pypdf`）。扫描件无可用文字时停止数字分析，请求可检索版本或经复核的 OCR。资料可联网从公司/交易所/巨潮获取，联网不可用时用用户提供的 PDF。记录 URL 和下载日期，不把旧报告称为最新。
3. 阅读 [输入规范](references/input-schema.md)。从新报告提取本期及其比较期，再从旧报告提取该比较期原始数。优先营业收入、归母净利润、扣非归母净利润、经营现金流、应收、存货、借款等；不要为凑数量补值。对每个数字确认表头、行名、单位、口径及 PDF 物理页。对关键页看原 PDF，文本匹配不能确认列是否选对。
4. 写 `work/input.json`。同名不同定义的指标不合并；营业总收入和营业收入分开。比率以 `percent` 录入，25.42 表示25.42%；变化用百分点。上期基数小于等于零时只给绝对变化，不生成通常意义的增长率。新旧基数不一致时保留三列，查找重述披露；无法确认可比性则该行标未核实。
5. 运行 `python3 scripts/compare.py work/input.json --sources work/sources.json --output work/result`。退出码0表示校验计算完成，**不代表全部行可比较**；检查每行状态和覆盖率。退出码2表示输入错误，修正后再运行。任何金额不可在产物里手工改成另一数字。
6. 对重要变化查管理层讨论、现金流说明和附注。将解释、页码和待核实问题录入输入后重跑。解释写“公司披露/管理层解释”；没有分项量化证据，不能把解释提升为已验证因果。用同口径金额与绝对规模选3–5项重点，不单纯按同比百分比排序；遗漏的关键项写明。
7. 在生成报告后附研究摘要，区分事实、公司解释、Agent 判断及待核实项。不要将现金流下降直接定性为造假或基本面恶化；不能把不同范围的经营现金流/归母净利润称为严格现金转化率。核对最新来源版本、重要合并范围变化与重述后才扩大结论。

## 验收

至少一个真实双 PDF 案例从提取到产物完整跑通。计算脚本可通过仓库 `tests/test_financial_report_changes.py` 验证单位换算、非正基数、百分点、缺数、口径冲突、重述与来源错误。测试只能说明已测范围；新公司的版式与会计事项仍需复核。
