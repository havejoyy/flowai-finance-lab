# 七步复盘字段与模板

## 标准 JSON 契约

- `schema_version`: 固定为 `daily-market-review/v1`。
- `trade_date/source/fetched_at/complete/errors`: 数据截面和完整性。
- `market`: 指数、全市场家数、涨跌家数及成交额。
- `sentiment`: 涨跌停、炸板、触板、炸板率与最高连板。
- `boards`: 行业维度的强度、涨停数量、成交及代表性标的。
- `stocks`: 用于按证券代码联动的全市场个股快照。
- `representative_stocks`: 涨停候选的连板、五日量比及前高信息。
- `limitations`: 自动推算边界；分析时不得省略。

联动输出 `market-longhubang-linked/v1` 保留完整 `market_review`、`longhubang`，并在 `cross_validation` 中按代码提供市场上下文。`matched` 只表示数据匹配，不表示五层证据自动通过。

## 最小输入

- 交易日期与数据截止时间
- 主要指数涨跌幅
- 两市成交额及前一交易日成交额
- 上涨、下跌、涨停、跌停家数及统计口径
- 炸板率或炸板数、触及涨停数
- 连板梯度与大幅回撤数量
- 强势板块及其驱动、持续天数、代表性标的
- 用户当天操作记录（可选）

## 输出模板

### 1. 数据说明

列明日期、来源、截止时间、缺失项和口径差异。

### 2. 大盘扫描

| 创业板指 |  |  |  |
| 两市成交额 |  | 前一日 |  |
| 上涨/下跌家数 |  |  |  |

### 3. 情绪温度

列出涨跌停、炸板率、连板高度和大幅回撤；给出“扩散、分化、收缩或无法判断”，并附证据和反证。

### 4. 主线与退潮

对每个候选方向记录：板块、强度证据、驱动、持续时间、梯队、反证、结论。避免仅凭单只股票定义主线。

### 5. 代表性标的与资金验证

只描述可核验的价格行为、板块带动和公开资金数据。龙虎榜席位、主力资金标签均是滞后或口径化数据，不得推导为确定性意图。

### 6. 个人决策复盘

逐笔记录：原计划、当时证据、实际动作、偏离点、结果、可改进规则。若用户未提供交易记录，提供空白模板，不虚构。

### 7. 下一交易日观察清单

最多列三种情形。每种情形写明：需要观察的事实、确认信号、失效信号、仍缺数据。不要分配概率或仓位，除非用户只是在回顾自己已经制定的规则。

## 质量检查

- 数字是否能回到来源？
- 结论是否混淆事实与推断？
- 是否遗漏反证或数据缺口？
- 是否出现个性化买卖、仓位或收益承诺？
