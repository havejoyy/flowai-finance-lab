# A股每日复盘

将零散的收盘数据整理成可追溯的七步复盘。只依据用户提供或可核验的数据工作；缺失项标记为“信息不足”，不得补造实时行情。

## 数据入口与自动获取

用户只提供交易日期时，从本 Skill 根目录执行：

```bash
# 标准市场快照 JSON
python3 scripts/fetch_market_review.py 2026-08-10 --json

# 与 longhubang-analysis 一键联动
python3 scripts/run_linked_review.py 2026-08-10 --json
```

脚本仅使用 Python 标准库，通过东方财富公开行情接口取得主要指数、全市场涨跌与成交、涨跌停/炸板推算、行业强度、涨停梯队和代表性标的。标准输出分别使用 `daily-market-review/v1` 与 `market-longhubang-linked/v1`。联动脚本按证券代码合并市场快照和龙虎榜，不按名称猜测。

自动结果的边界：全市场快照接口只用于最近交易日，脚本会用上证指数最近交易日校验日期，禁止把实时快照错配到历史日期；行业“主线候选”是规则筛选，不等于人工确认主线；炸板由最高价和收盘价推算；新闻驱动、首次封板时间和板块带动性取不到时必须标记“信息不足”。接口失败时报告真实错误，不生成事实结论。

## 执行顺序

1. **确认数据截面**：记录交易日期、数据来源、统计口径和截止时间。若用户只说“今天”，先确认实际日期。
2. **扫描大盘**：汇总主要指数涨跌、两市成交额、较前一日变化和涨跌家数；区分事实与市场定性。
3. **定位情绪**：检查涨停、跌停、炸板率、连板梯度和大幅回撤数量。证据不足时不要硬判情绪周期。
4. **梳理主线**：按板块强度、持续时间、驱动类型和梯队完整度区分持续主线、轮动和单日异动。
5. **跟踪代表性标的与资金**：记录其板块地位、价格行为和公开资金线索，不把席位或资金流向等同于未来涨跌。
6. **复盘用户决策**：逐笔区分计划内操作与临时操作，追问当时证据、退出条件和偏离计划的原因。不要羞辱或替用户归因。
7. **形成观察预案**：写出下一交易日需要验证的情形、触发信号和失效信号，只给观察条件，不给仓位、买卖点或收益预测。

详细字段和输出模板见 [references/review-framework.md](references/review-framework.md)。

## 数据与推理规则

- 对实时或当日数据优先运行随包脚本；无法访问时报告错误并要求用户提供数据。
- 每个结论分别标注“事实”“推断”或“信息不足”。
- 所有数量写明单位和统计口径，例如“亿元”“剔除ST”。
- 对板块强弱、情绪阶段等推断列出至少两项支持证据，并给出反证或不确定性。
- 不根据不完整数据填写不存在的精确概率。
- 不输出“可以买入”“应卖出”“仓位几成”“目标价”等个性化交易指令。

## 输出结构

依次输出：数据说明、大盘扫描、情绪温度、主线与退潮、代表性标的、资金验证、个人决策复盘、下一交易日观察清单、数据缺口与风险提示。

结尾固定说明：

> 本复盘仅用于信息整理和学习研究，不构成投资建议、收益承诺或任何交易指令。市场有风险，决策需独立核验。
